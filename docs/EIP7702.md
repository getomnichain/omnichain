# EIP-7702 (type-4) transactions

Opt-in per chain: pass `supports7702: true` to the `EvmChain` constructor. Methods below throw `ChainError(FeatureNotSupported)` on unflagged chains.

## Flow

```ts
import { EvmChain } from '@getomnichain/omnichain';

const chain = new EvmChain({
  chainId: 1,
  name: 'Mainnet',
  blockTimeSeconds: 12,
  nativeSymbol: 'ETH',
  explorerBaseUrl: 'https://etherscan.io',
  rpcUrl: process.env.MAINNET_RPC_URL,
  supports7702: true,
});

// 1. Read current delegate (nullable)
const current = await chain.getDelegation(userAddress);
// current === null | { delegate: '0x...' }

// 2. Compute the authorization digest for the wallet to sign
const nonce = await chain.getPendingNonce(userAddress);
const digest = chain.buildAuthorizationDigest({
  delegate: newDelegateAddress,
  nonce,
  chainId: 1,
});

// 3. Wallet signs the digest externally
const signature = await wallet.signRaw(digest);  // returns { r, s, yParity }

// 4. Build the type-4 tx via the general primitive
const unsigned = await chain.createUnsignedTransaction({
  from: userAddress,
  to: userAddress,                       // 7702 self-call to establish delegation
  data: '0x',
  authorizationList: [{
    chainId: 1,
    delegate: newDelegateAddress,
    nonce,
    signature,
  }],
});

// 5. Sign + broadcast
const signedHex = await wallet.signTransaction(unsigned);
const txHash = await chain.broadcast(signedHex);

// 6. Wait for inclusion
const status = await chain.getTransactionStatus(txHash, { wait: true, timeoutMs: 30_000 });
```

## Guards

- `authorizationList` must be non-empty when provided (`InvalidArgument`).
- Every `authorizationList[i].chainId` must match `chain.chainId` OR be `0` (EIP-7702 wildcard). Cross-chain replay guard.
- `supports7702 === false` → `FeatureNotSupported` before any wire call.
- `getDelegation` parses ONLY `0xef0100<20-byte-delegate>` (exact 24-byte code). Any other shape returns `null`.

## Digest formula

`keccak256(0x05 || rlp([chainId, delegate, nonce]))` per the EIP.
